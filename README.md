# Amiga AGBear

AG Bear themed AmigaOS programs.

## AG Bear 2.0 (current)

Two programs for an AGA Amiga (A1200/A4000) or an Amiga with a graphics card, AmigaOS 3.0+:

- **AG Bear Pet** (`src/pet/agbearpet.c`) - the AG Bear Tamagotchi, expanded: look after AG Bear at
  home (feed, bath, nap, medicine, balloon memory game, dress up), play fetch and have picnics in the
  garden, meet his friends Rosie and Pip in the park (say hello, play tag, give presents, swings, the
  Catch the honey game), and shop at Honey's shop for food, medicine, a ball, presents, sunglasses
  and a party hat. Friends visit when they like him enough; a golden crown can be won.
- **AG Bear Talker** (`src/talker/agbeartalker.c`) - type something and AG Bear says it, with his
  real moving mouth. Dress him up (hats, glasses, bow ties, a moustache), change his fur colour
  (including Rainbow), the backdrop (including Disco and Space) and his voice; jokes, a song, a
  surprise outfit button and photos saved to RAM: as IFF pictures.

Both use their own 256-colour screen with a flicker-free renderer (`src/common/agb_gfx.c`), the
original AG Bear sound samples (`src/common/agb_audio.c`) and narrator.device speech when it is
installed (bear noises otherwise). See `docs/ReadMe.txt` (shipped as the ReadMe).

### Building

```bash
make            # build/AGBearPet, build/AGBearTalker (m68k-amigaos-gcc, -m68020-60)
make release    # release/AGBear drawer with Workbench icons and the ReadMe
make assets     # re-generate art/ and src/gen/ (Python 3 + Pillow + numpy) after changing pictures/sounds
make icons      # re-generate the Workbench icons in wbicons/
```

`src/gen/` is generated by `tools/mkassets.py` from the original pictures and sounds (and the new
park/shop/dress-up art drawn by `tools/mkart.py` into `art/`); it is committed so a build only needs
the cross compiler.

## The original prototypes

Kept as they were, for preservation.

This repository contains experimental AmigaOS applications based around an AG Bear-style talking bear / virtual pet concept.

## Status

Prototype / preservation state.

This project is being preserved first and cleaned later. Some files are experimental and may require specific AmigaOS libraries, image assets, or sound files to run correctly.

## Included Projects

### AG Bear Talker

A talking AG Bear app using:

- `narrator.device`
- `translator.library`
- GadTools UI
- ILBM background image
- mouth open/closed overlays

### AG Bear Virtual Pet Prototype

A larger Tamagotchi-style AG Bear prototype using:

- Hardware BOB/sprite-style rendering experiments
- GadTools UI
- timer.device
- narrator.device / translator.library
- icons for actions such as play, clean, sleep, medicine and stats
- sound effect support
- simple virtual pet behaviour

## Target

- AmigaOS 3.x
- m68k-amigaos-gcc / Bebbo GCC
- picture.datatype for ILBM loading
- narrator.device and translator.library for speech

## Files

- `ag-bear-protov4.c` - larger AG Bear virtual pet prototype
- `AGBear-Talker/` - talking AG Bear app / related files
- `icons/` - ILBM icon assets
- `sounds/` - sound assets
- `Old-ProtoTypes/` - older experiments retained for reference
